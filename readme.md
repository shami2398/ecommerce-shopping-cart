# 🛒 E-Commerce Shopping Cart

A full-stack E-Commerce Shopping Cart web application built using Node.js, Express.js, MongoDB Atlas, HTML, CSS, and JavaScript.

---

## 🚀 Features

### Authentication
- User Registration
- User Login
- Password Hashing using bcrypt

### Products
- Add Products
- View Products
- Product Details

### Cart
- Add To Cart
- View Cart
- Remove From Cart
- Checkout

### Database
- MongoDB Atlas Integration

---

## 🛠 Tech Stack

### Frontend
- HTML
- CSS
- JavaScript

### Backend
- Node.js
- Express.js

### Database
- MongoDB Atlas
- Mongoose

### Security
- bcryptjs

## ⚙ Installation

### Clone Repository

```bash
git clone <repository-url>
```

### Install Dependencies

```bash
npm install
```

### Start Server

```bash
npm run dev
```

Server runs on:

```bash
http://localhost:5000
```
